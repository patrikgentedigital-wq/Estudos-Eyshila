## 2026-10-16 - [Dashboard O(N*M) Re-Render Bottleneck Fixed]
**Learning:** React re-renders on the Dashboard were causing severe O(N*M) performance drops because the `StudyHeatmap` looped through `daysInMonth` (M) and for each day iterated over all past `attempts` (N), parsing dates. When the user rapidly triggered state changes (e.g., typing in the `Caderno de Erros` text input), these expensive calculations were invoked repeatedly because neither `Dashboard` nor `StudyHeatmap` had memoized their derived states or components. This is a critical codebase-specific performance anti-pattern.
**Action:** Always wrap expensive derived states, especially those iterating over variable-length lists like `attempts` or `modules`, inside `React.useMemo`. Always group related states using `Maps` upfront to drop nested loops from O(N*M) down to O(N)+O(M). Finally, use `React.memo` on stateless/presentational components like `StudyHeatmap` that receive heavy props.
